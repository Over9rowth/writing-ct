# 文风体检台（WritingCT）

> **中文文章客观 CT 诊断与结构度量仪**  
> 一套 100% 本机离线运行的个人文本观测仪器。

---

## 它是什么

文风体检台通过智能分句状态机、句长统计与局部变异系数（CV）、常见口头禅/虚词雷达及实义重复 N-gram 探针，对用户输入的文本进行纯客观结构显影。

- **智能分句**：感知中英文引号与括号闭合边界，保证对话引用不被切碎；
- **长难句曝光**：自动统计句长分布（均值、标准差、中位数、P90），标出超长长难句；
- **机械节奏诊断**：利用滑动窗口变异系数（CV < 0.08）识别连续等长的机械排比或流水账段落；
- **口头禅雷达**：内置 4 大类 32 种高频赘词词库，量化千字出现率并高亮标出具体出现位置；
- **重复 N-gram 词组**：自动提取 2~4 元汉字重复词组，内置虚词停用词过滤，直观呈现复用短语。

---

## 它不是什么

- **它不是 AI 润色工具**：不会自动帮你改写文章，更不会替你生成文字；
- **它不是主观文采裁判**：不评价文章“写得好不好”，只陈述统计事实；
- **它不是云端服务**：100% 本地运行，不上传任何文字，完全保护隐私。

